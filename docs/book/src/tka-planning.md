# Virtual TKA planning

Phase-6 milestone: `knee-replacement-planning` example — plane osteotomy on
a voxel femur, rigid fragment reposition (rotation about the
transepicondylar axis + distal translation), and component sizing from
landmarks with interpolated size charts.

The sizing crate also reports alignment proxies (femorotibial angle, tibial
slope) from the same landmark set.
