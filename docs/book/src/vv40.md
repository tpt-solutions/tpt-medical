# Credibility assessment (ASME V&V 40)

`tpt-med-vv40` encodes the risk × influence matrix: each question of
interest declares model risk and model influence; the matrix prescribes
credibility goals (minimum verification/validation activity types,
quantitative-agreement requirement, independent code review).
`CredibilityAssessment::evaluate()` returns unmet goals; `is_credible()`
is the pass/fail summary. The matrix is monotone along both axes (tested).

Worked example: the femur stance-screening question (medium risk /
significant influence) ships with the golden dataset
`test-data/golden/regulatory/vv40_credibility_matrix.json`.
