The WASM engine lives in web/pkg/ — build it once with scripts/build-web.ps1 (or .sh), then serve the repository root:

python -m http.server 8080
open http://localhost:8080/web/stent-simulator/
Research use only. Not FDA cleared. All simulation runs in your browser.

The same engine as the viewer, packaged as a brandable custom element. Change the controls — the component, its accent, and the embed snippet below all update live. Drop the element into any MedTech marketing or configurator page; nothing leaves the visitor's browser.
