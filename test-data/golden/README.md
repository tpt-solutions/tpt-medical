# Golden Reference Datasets

Curated reference values for regression verification (ASME V&V 40
*calculation verification* and change-control). Each JSON documents the
model, provenance, units, expected metrics, and tolerances.

## Provenance classes

- `analytical` — closed-form solution (exact; tight tolerance).
- `synthetic-model` — reference run on the **committed synthetic phantom**
  (`test-data/dicom/synthetic_ct`, generated by `gen-synthetic-ct`). Values
  are regression anchors, not clinical claims.
- `literature-band` — order-of-magnitude screen against published data
  (documented source); loose tolerance.

## Regeneration

Unless noted, reference values are regenerated by the corresponding example
binary, e.g.:

```console
cargo run -p tpt-med-examples --bin femur-stress-analysis
cargo run -p tpt-med-examples --bin stent-deployment
cargo run -p tpt-med-examples --bin carotid-wss-screening
cargo run -p tpt-med-examples --bin fda-package
```

## Policy

A PR that changes any golden value must (a) explain the numerical change in
the PR description, (b) state which verification test covers the change, and
(c) bump the relevant crate version per SemVer (numerical behavior is API).

**Synthetic data only.** Real patient data must never be committed here.
