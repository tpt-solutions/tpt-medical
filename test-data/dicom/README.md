# Synthetic DICOM test data

`synthetic_ct/` contains a **synthetic** proximal-femur-like CT phantom
(48x48x24 voxels, 1 mm isotropic, explicit VR little endian) generated by:

```console
cargo run -p tpt-med-examples --bin gen-synthetic-ct -- \
    test-data/dicom/synthetic_ct --cols 48 --rows 48 --slices 24
```

Composition: cortical shell (700 HU) around a trabecular core (150 HU) in a
soft-tissue background (50 HU), air outside.

**Never commit real patient data (PHI) to this repository.**
